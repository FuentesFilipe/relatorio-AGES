\section[Desenvolvimento do Projeto]{Desenvolvimento do Projeto}
Esta seção apresenta os artefatos desenvolvidos durante o semestre, as etapas
de sua elaboração, as ilustrações e os respectivos links.

\subsection{Repositório do Código Fonte do Projeto}
Inicialmente, foram criados cinco repositórios para o projeto: “Wiki”, “App”,
“Web”, “Auth” e “Api”. O repositório “Wiki” reunia a documentação do trabalho,
incluindo o fluxo de trabalho, a arquitetura, o \textit{design} e os
\textit{mockups}, entre outras informações. “App” e “Web” continham o código do
\textit{frontend} para dispositivos móveis e para a Web, respectivamente. Já
“Auth” e “Api” continham a lógica do \textit{backend} do projeto.

Ao longo do semestre, foram criados mais dois repositórios. “Infrastructure”
armazenava os arquivos de configuração de \ac{cicd} e as configurações na
nuvem. Por fim, para os testes \ac{e2e} do sistema, foi criado o repositório
“E2E Tests”, que utilizava \textit{Selenium}. Todos os repositórios podem ser
encontrados em \url{https://tools.ages.pucrs.br/vitimas-de-crime}.

\subsection{Tecnologias Utilizadas}
As \acp{api} da aplicação e de autenticação foram implementadas em Kotlin com
Spring Boot, usando Gradle para gerenciar as dependências
\cite{kotlin,spring-boot,gradle}. Os testes de sistema foram mantidos no
repositório “E2E Tests” e utilizaram Selenium \cite{selenium}. A autenticação
foi gerenciada pelo Keycloak, que implementa o protocolo OAuth 2
\cite{keycloak,oauth2}.

Além disso, foram utilizados recursos da \ac{aws}, incluindo \ac{s3} e
\ac{eks}. Para facilitar a configuração em diferentes ambientes e melhorar a
escalabilidade, optamos pelo uso de contêineres Docker. No \textit{frontend},
TypeScript foi a linguagem principal, com React Native e Expo no desenvolvimento
móvel e React JS no desenvolvimento Web
\cite{aws-docs,docker,typescript,react-native,expo,react}.
